CARA ORDER

Ikuti langkah singkat berikut
01 — Pilih game
Masuk ke Top Up Game lalu pilih Mobile Legends atau Free Fire.
02 — Isi data & nominal
Masukkan ID game dengan benar, pilih nominal, lalu cek harga.
03 — Bayar
Pilih metode pembayaran yang tersedia dan salin detail pembayaran.
04 — Konfirmasi
Klik “Saya Sudah Bayar”, lalu hubungi admin WhatsApp untuk pengecekan pembayaran.
Berapa lama proses top up?

Pesanan diproses setelah pembayaran berhasil diverifikasi admin. Waktu proses dapat berbeda tergantung kondisi layanan.

Kalau salah memasukkan ID game?

Periksa kembali ID sebelum melakukan pembayaran. Jika sudah terlanjur, segera hubungi admin dan sertakan Order ID.

Apakah status pembayaran otomatis?

Tidak. Website mencatat order sebagai pending dan admin melakukan verifikasi uang masuk sebelum order diproses.

Kalau ada masalah saat order?

Simpan Order ID dan hubungi admin melalui WhatsApp agar pesanan lebih mudah ditemukan.
